Privacy Policy

JKS1980 Backup and this site · Last updated 15 November 2026

Who runs this

JKS1980 Backup is a personal tool built and used by JKS1980 for backing up his own files. It has no other users and is not offered to the public.

What JKS1980 Backup accesses

The app asks Google for one permission: drive.file, which lets it see and change only the files it created itself in the signed-in user's Google Drive. It cannot read any other files, email, contacts or account details.

What it stores, and where

  • Backups of the owner's own files, encrypted on the owner's home server before upload. Google cannot read their contents.
  • The sign-in token Google issues, kept only on the owner's home server.

What it does not do

  • No data is sold, shared, or given to anyone.
  • No advertising, analytics or tracking, in the app or on this site.
  • Google user data is not used to train AI or machine-learning models.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and data

Access can be withdrawn at any time at myaccount.google.com/permissions. Deleting the app's backup folder in Google Drive removes all stored data.

This website

This site is hosted on GitHub Pages and sets no cookies. GitHub may log visitors' IP addresses for security, as described in the GitHub Privacy Statement.
